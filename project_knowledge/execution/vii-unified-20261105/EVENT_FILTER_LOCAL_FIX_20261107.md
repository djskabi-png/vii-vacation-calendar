# תיקון סינון אירועים, שמור מקומית בלבד

לא פורסמה גרסה. האתר הציבורי נשאר בגרסה 814.

תוקנה אי התאמה בין סוגי המקום ביחיד וברבים, שהפכה חיפוש לופטים לתוצאות ריקות. תוקנה הצגת "הכל" בבורר כאשר האזור שנבחר חסר בנתוני האפשרויות שנטענו. אזורי האירועים הראשיים זמינים גם לפני טעינת נתוני הקטלוג והגאוגרפיה. אותה הגנה הוחלה בבורר האזור של חדרים לפי שעה, עם תמיכה בתווית מתורגמת.

אימות מקומי: לופטים בצפון 7, לופטים בדרום 6, כל האירועים בדרום 12. נבדקו בחירה דרך הממשק, רענון, חזרה לאחור, תצוגת רשימה ואיפוס. נבדק נייד ברוחב 390. נבדקו גם שמירת אזור ומאפיין בנופש ובספא ושמירת אזור לפי שעה.

57 בדיקות עברו, בדיקת טיפוסים עברה. בדיקות ההתנהגות נוספו לחובת בדיקות השחרור של חיפוש, אירועים ולפי שעה.
