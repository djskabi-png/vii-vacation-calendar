## Artifact transfer finding

Comparing 1248 output paths across two builds with identical deployable source
inputs found twelve changed/renamed server outputs. The framework generates
private draft/prerender secrets at build time. Those must remain unpredictable
and must never be printed, source-derived or copied into project notes.

The source-input build identity therefore does not prove an identical compiled
artifact. The strict artifact digest gate remains required. The supported
Sites package helper can package the already tested dist without rebuilding.
The next release must transfer that exact archive, not claim equivalence for
a remote rebuild. No archive was uploaded and no Site/Edge version was
published during this phase.
