## Confirmed tooling repair and remaining diagnosis

The browser allowlist omitted VII's actual image CDN. Root reproduced the
original private engine aborting an owned responsive-media image request where
the regression expected it to continue. The local repair admits only image GETs
matching the exact owned origin, path, hashed media source, width and quality.
It retains the180-request limit and all business-write denials. The repair is
not yet active at this checkpoint.

Other original failures include automatic POST attempts whose paths were
redacted, request-budget excesses and action/navigation timeouts. Their causes
are not all established. New local diagnostics classify fixed resource/write
kinds without recording URLs, bodies, query strings or header values. Final
counters also prevent late context-close callbacks producing a contradictory
passing receipt. Optional standard browser navigation timings preserve missing
stages as null and do not perform a reload or an additional network request.

Before publishing those diagnostics, root found a separate compiled-artifact
defect: Wrangler inserted an outer `__name` helper inside the function serialized
to the browser. The actual phase47 bundle reproduced `__name is not defined`.
That artifact was not deployed. The repair uses a literal read-only browser
script, and an actual keep-names compilation/isolation regression now covers
the mechanism. The final packaged callback must also pass the equivalent exact
bundle readback before activation. Source tests alone do not satisfy this gate.

Current delivery timings must be distinguished from cached upstream timing
headers. A real RSC HIT carried older `Server-Timing` Edge values as well as the
current lookup value. Do not attribute stored timings to the current request.
The CUA read-only page scope exposes no `performance` object; its manual UI
checks cannot supply NavigationTiming/FCP samples. No synthetic48-row matrix
or field percentile was accepted.

The independent native artifact review contained an invalid future timestamp.
Root preserved that report, recomputed actual module/config/test-log hashes
and reconciled the original provider deployment without resending it. A resource
recording failure also occurred after the deploy child started because an agent
had overwritten the resource manifest schema. The original deployment succeeded
and was verified by exact provider readback; no second deploy was attempted.
Preserve manifest schemas and check them before launching a process.
